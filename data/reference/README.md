# data/reference

Небольшие справочники, которые хранятся в git: регионы и федеральные округа, коды ОКВЭД и профессий (ОКЗ / ОКПДТР). Заполняются на этапе 2 после проверки источников.

## hh/
- `ru_dictionaries.json` — справочник перечислений hh.ru (api.hh.ru/dictionaries), 2026-11-19.
- `ru_areas_russia.json` — регионы России из api.hh.ru/areas (Россия, 89 регионов; без вложенных городов).
- `monthly_reports_2026/` — 10 PDF «Краткий обзор рынка труда» hh.ru, январь–октябрь 2026. Разбор: `tools/parse_hh_monthly.py`.
