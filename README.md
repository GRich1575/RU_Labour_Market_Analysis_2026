# Анализ рынка труда РФ за 2026

Обзор статистики рынка труда России за 2026 год: тренды, прогноз, дашборды.

> **Впервые в проекте?** Начните с `docs/START_HERE.md` — порядок чтения и главные правила.

## Цели
1. Выявить шоки и их влияние на инфляцию.
2. Соотношение вакансий и безработных; сегментация по сферам (дефицит и избыток рабочей силы).
3. Детализация по малому и среднему бизнесу (МСП).

## Структура репозитория
```
config/      реестр источников (sources.yaml)
docs/        документация (RU): START_HERE, источники, установка, шпаргалки
docs/stage1/ бриф и журнал проверок источников этапа 1
docs/team/   командная политика (отключена)
docs/homework/ необязательная инструкция по установке для новичков
data/        данные: raw (не в git), processed (не в git), reference (справочники)
PROGRESS.md  текущее состояние работ
```
Папки `src/`, `tests/`, `dashboards/` добавляются на следующих этапах.

## Установка
Python 3.11+, виртуальное окружение и библиотеки: `pip install -r requirements.txt`.
Подробно (программы, библиотеки, форматы файлов): `docs/prerequisites.md`.

## Статус
Этап 1 — сбор и структурирование источников данных. См. `PROGRESS.md`.
