# Источники данных: описание и порядок использования

Полный реестр (адреса, форматы, статус проверки) — `config/sources.yaml`. Этот документ объясняет, как источники сочетаются.

## 1. Роли источников

| Роль | Источники | Для чего |
|---|---|---|
| База | Росстат, ОРС | Официальный уровень безработицы по методологии МОТ; сопоставим с другими странами |
| Сверка | Роструд, Росстат (неполная занятость, простои), Банк России (мониторинг предприятий) | Проверка базы, скрытая безработица |
| Опережающие / независимые | hh.ru, СберИндекс, ИСИЭЗ ВШЭ, ЦеТИ, ЦМАКП | Оперативный разворот рынка; сверка трендов |
| Микро | RLMS-HSE | Зарплаты, неформальность (научный анализ) |
| Справка | ILOSTAT, OECD | Межстрановое сравнение; **не** независимая проверка (перепечатка Росстата) |

## 2. Правила работы с источниками

1. **Не смешивать понятия.** Безработица по МОТ (ОРС) и зарегистрированная безработица (Роструд) — разные величины, их нельзя сравнивать напрямую.
2. **Ряды брать из ЕМИСС** (fedstat.ru), где возможна выгрузка. Номер показателя фиксировать в реестре.
3. **Сырые файлы не менять.** Скачанный файл кладётся в `data/raw/<id>/` как есть; рядом — дата загрузки и адрес.
4. **Ошибка выборки.** ОРС — выборочное обследование. При уровне безработицы около 2% небольшие изменения могут быть шумом; в графиках — оговорка или доверительный интервал.
5. **Расхождения — тоже результат.** Если официальный уровень стабилен, а hh-индекс резко растёт, это гипотеза о скрытой безработице (неполная занятость, простои), а не ошибка данных. Проверять по строке «неполная занятость» Росстата.
6. **Закрытие рядов.** Росстат с 2026 г. закрыл часть показателей (зарплаты бюджетников, ЖКХ, демография, миграция). Поэтому каждый скачанный ряд сохраняется в `data/raw/` сразу, с датой.
7. **Условия использования.** Для hh.ru, СберИндекса и RLMS-HSE проверить разрешённые способы использования до публикации результатов.

## 3. Открытые вопросы по источникам

- Публикуется ли безработица по профессиям или отраслям? Без этого цель №2 (сегментация) опирается на прокси (hh по профессиям, Роструд).
- Есть ли у СберИндекса публичная выгрузка? Поиск не подтвердил.
- Доступен ли API hh.ru для вакансий по профессиям, и с какими лимитами?
- Какой точный ID показателя ОРС в ЕМИСС?

Все статусы в реестре — `to_verify` до ручной проверки адреса и формата.
