# CSV — формат и шпаргалка

Стандарт проекта: `data/processed/` и `data/reference/`.
- Кодировка: UTF-8 (для чтения в Excel на Windows — `utf-8-sig`, с BOM).
- Разделитель: `;`.
- Десятичный знак: зафиксировать в README папки (запятая или точка).
- Первая строка — заголовок. Без пустых строк и «шапки» отчёта.

## Пример (длинный формат)
```
дата;регион;показатель;значение;единица;источник
2025-01;РФ;безработица;2.2;%;rosstat_orc
```

## pandas
```python
df = pd.read_csv("file.csv", sep=";", encoding="utf-8-sig", decimal=",", dtype={"регион": str})
df.to_csv("file.csv", sep=";", index=False, encoding="utf-8", decimal=",")
```

## Проверка «сырого» файла (без вывода всего файла)
```powershell
# Windows (PowerShell)
Get-Content file.csv -TotalCount 5
```
```bash
# macOS / Linux
head -n 5 file.csv
```
Не открывать большие CSV целиком: это правило проекта.

## Открыть в Excel
- Windows: двойной клик даст ANSI; для UTF-8 — «Данные → Из текста/CSV», кодировка «65001 UTF-8», разделитель «;».
- macOS: Excel → «Данные → Получить данные → Из текста/CSV», кодировка UTF-8, разделитель «;».
- Linux: LibreOffice Calc → «Кодировка: Unicode (UTF-8)», разделитель «;».

## Ловушки
- Excel на Windows по умолчанию открывает CSV в ANSI — сохранять как `utf-8-sig` или импортировать через «Данные → Из текста».
- `decimal=","` обязателен, если в файле `2,2`; иначе колонка станет строкой.
- Числа с пробелом-разделителем тысяч (`1 234`) — убрать до `to_numeric`.
- Ведущие нули в кодах (`01`) — читать как `dtype=str`.
- Разделитель `;` выбран потому, что десятичная запятая конфликтует с `,` как разделителем.
