# Markdown — шпаргалка

Используется в `README.md`, `PROGRESS.md`, `docs/`.

## Заголовки
```
# Уровень 1
## Уровень 2
### Уровень 3
```

## Текст
```
**жирный**    *курсив*    `код`
- пункт списка
1. нумерованный
```

## Ссылки и изображения
```
[текст](docs/prerequisites.md)
![подпись](path/to/image.png)
```
- Ссылки на файлы — относительные пути от текущего файла.

## Код
````
```python
print("hello")
```
````
Указывать язык после тройных обратных кавычек (`python`, `powershell`, `bash`, `yaml`).

## Таблица
```
| Колонка | Описание |
|---|---|
| id | уникальный код |
```

## Чеклист
```
- [x] сделано
- [ ] не сделано
```

## Ловушки
- Пустая строка перед списком и таблицей обязательна.
- В таблице символ `|` внутри ячейки экранировать: `\|`.
- `PROGRESS.md` — не более 60 строк (правило проекта).
