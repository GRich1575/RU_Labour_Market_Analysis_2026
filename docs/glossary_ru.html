Глоссарий проекта

Термины проекта: экономика рынка труда, статистика, данные, технологии и командная работа. Для каждого термина — краткое пояснение и ссылки для углублённого изучения на русском и английском языках (для перекрёстной проверки).

Обозначения в ссылках:
— — официального аналога на этом языке нет или ссылка не нужна;
‡ — ссылка не открылась из среды проверки (возможно, ограничение доступа); проверьте в браузере.
