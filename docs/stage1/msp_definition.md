# Определение субъектов МСП — рабочая версия для проекта

Источник: ФЗ № 209-ФЗ от 24.07.2007 (ст. 4); ПП РФ № 265 от 04.04.2016; ПП РФ № 1412. Файл-источник: `kriterii_msp_rf.pdf` (скачан 2026-11-18). Машиночитаемая версия: `config/msp_criteria.yaml`. Перед расчётами — сверить редакцию ст. 4 на pravo.gov.ru.

## 1. Кто относится к МСП
Юридические лица и ИП, зарегистрированные в установленном порядке и внесённые в Единый реестр субъектов МСП (ФНС, https://mmsp.nalog.ru/). Допустимые формы: ООО, АО, хозяйственные товарищества и партнёрства, производственные и потребительские кооперативы, КФХ, ИП.

## 2. Категория (алгоритм)
1. Определить категорию по **доходу** за предыдущий календарный год: микро ≤ 120 млн ₽; малое ≤ 800 млн ₽; среднее ≤ 2 млрд ₽.
2. Определить категорию по **среднесписочной численности** работников: микро ≤ 15; малое 16–100; среднее 101–250.
   - Исключения по численности для среднего: лёгкая промышленность (перечень ПП № 1412) — до 1 000; общественное питание (ОКВЭД 2, класс 56) — до 1 500.
3. Итоговая категория — **большая** из двух (по доходу и по численности).
4. Пример: 12 работников, выручка 900 млн ₽ → по численности микро, по доходу среднее → итог **среднее**.

Доход и численность берутся за предыдущий календарный год. Численность включает работников по ГПХ и совместителей (с учётом отработанного времени) и работников филиалов и представительств.

## 3. Особые случаи
- **Вновь созданные** (регистрация с 1 декабря предыдущего года по 31 мая текущего года) — автоматически микро.
- **ИП на ПСН без наёмных работников** — микро.
- **Сколково и ИНТЦ** (освобождены от сдачи отчётности о доходе) — только по численности; для ИНТЦ с 1 сентября 2026.
- **Правило трёх лет:** категория меняется, а статус утрачивается, только если пределы по доходу или численности превышены три календарных года подряд.

## 4. Доли в уставном капитале (только ООО, АО, товарищества и партнёрства)
- РФ, субъекты РФ, муниципалитеты, общественные и религиозные организации, благотворительные и иные фонды (кроме инвестиционных фондов) — **не более 25%** суммарно.
- Иностранные юридические лица и российские юридические лица, не являющиеся субъектами МСП, — **не более 49%** суммарно.
- Доли физических лиц и МСП не ограничены.
- Исключения: высокотехнологичный сектор; внедрение РИД; «Сколково» и инновационная инфраструктура; объединения инвалидов (≥50% инвалидов в штате, ≥25% ФОТ); вновь созданные ООО и АО — 49% временно не применяется при включении в реестр.
- Нарушение долей → исключение из реестра при ближайшем обновлении (правило трёх лет здесь не применяется).

## 5. Что это значит для данных проекта
- В таблицах Росстата из `data/raw/rosstat_smb/` (регистрация на 1 октября 2026) МСП **не выделены**: только организации и ИП по видам деятельности, формам собственности и организационно-правовым формам. Для Цели 3 нужны данные, которые позволяют применить критерии к отдельным организациям или агрегатам.
- Росстат в своей статистике использует **только численность** (малые предприятия — 16–100 работников, включая микро — по методологии Росстата). Это не совпадает с законом: доход в расчёт не входит.
- Варианты для Цели 3:
  1. Использовать Единый реестр МСП (ФНС, mmsp.nalog.ru) — если доступны выгрузки; это ближе всего к закону.
  2. Использовать статистику Росстата по малым предприятиям — с оговоркой: только численность.
  3. Оба варианта, с явной пометкой, какой критерий применён.
