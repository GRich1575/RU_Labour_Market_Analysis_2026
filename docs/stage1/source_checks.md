## Дополнительные находки
- hh.ru, статья «интерактивная карта рынка труда» (https://hh.ru/article/304204, из поиска, не открыта): по сообщению — 84 региона, 28 профессиональных сфер, ежемесячно с 2015 г. Возможный источник для цели 2 (сегментация по сферам), если ОРС не даёт безработицу по профессиям. Требует проверки.
- Реестр `rlms_hse`: в формате указан CSV — на странице указаны SPSS и Stata; формат исправлен в реестре.
- Адрес `hse_isiez` в реестре не работает (404).
