# references — исходные файлы, использованные в этапе 1

**Только для чтения и ознакомления.** Файлы здесь не редактируются и не используются как входные данные для извлечения и расчётов.

Для работы (извлечение, вычисления, парсинг) используется `data/raw/` (рабочие копии, не в git) и `data/processed/` (результаты, не в git). Файлы в `references/` — опубликованные документы, сохранены в git для проверки источников. Переименованы законы и постановления по схеме «вид_дата_номер»; содержимое не изменено.
